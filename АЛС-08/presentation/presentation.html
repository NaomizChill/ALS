Цель работы

Цель лабораторной работы

Приобретение практических навыков настройки сетевых сервисов:

  • DNS (Domain Name System)
  • DHCP (Dynamic Host Configuration Protocol)

Задачи

  • Добавить и настроить DNS-сервер
  • Настроить DHCP на маршрутизаторе
  • Перевести клиентов на динамическую адресацию
  • Проверить связность сети
  • Изучить процесс DHCP в режиме симуляции

Топология сети

Настройка DNS-сервера

Конфигурация IP

DNS-записи

  • www.donskaya.rudn.ru → 10.128.0.2
  • file.donskaya.rudn.ru → 10.128.0.3
  • mail.donskaya.rudn.ru → 10.128.0.4
  • dns.donskaya.rudn.ru → 10.128.0.5

Настройка DHCP

Параметры DHCP

  • шлюз: .1
  • DNS: 10.128.0.5
  • исключены адреса:
    • .1–.29
    • .200–.254

Проверка DHCP

Информация о пулах

  • Пулы созданы корректно
  • Адреса распределяются автоматически
  • Есть активные выдачи

Выданные адреса

  • 10.128.3.30, 10.128.3.31
  • 10.128.4.30
  • 10.128.5.30
  • 10.128.6.30, 10.128.6.31

Клиенты DHCP

Получение параметров

  • Клиенты переведены на DHCP
  • Автоматически получены:
    • IP-адрес
    • шлюз
    • DNS

Проверка связности

Тестирование сети

  • Выполнен ping между подсетями
  • Связность подтверждена
  • Первый пакет теряется (ARP)

Работа DHCP (симуляция)

Этапы DHCP

  • Discover
  • Offer
  • Request
  • ACK

Discover

  • Клиент отправляет broadcast
  • IP = 0.0.0.0

Offer

  • Сервер предлагает IP
  • Пример: 10.128.4.30

Request

  • Клиент подтверждает выбор

ACK

  • Сервер закрепляет адрес
  • Передаются параметры сети
