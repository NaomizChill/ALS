# Цель работы

## Цель лабораторной работы

Приобретение практических навыков настройки сетевых сервисов:

- DNS (Domain Name System)
- DHCP (Dynamic Host Configuration Protocol)

## Задачи

- Добавить и настроить DNS-сервер
- Настроить DHCP на маршрутизаторе
- Перевести клиентов на динамическую адресацию
- Проверить связность сети
- Изучить процесс DHCP в режиме симуляции

# Настройка DHCP

## Параметры DHCP

- шлюз: *.1*  
- DNS: 10.128.0.5  
- исключены адреса:
  - *.1–.29*
  - *.200–.254*

# Работа DHCP (симуляция)

## Этапы DHCP

- Discover  
- Offer  
- Request  
- ACK  

## Discover

- Клиент отправляет broadcast
- IP = 0.0.0.0

![Discover](10.png)

## Offer

- Сервер предлагает IP
- Пример: 10.128.4.30

![Offer](11.png)

## Request

- Клиент подтверждает выбор

![Request](12.png)

## ACK

- Сервер закрепляет адрес
- Передаются параметры сети

![ACK](13.png)
