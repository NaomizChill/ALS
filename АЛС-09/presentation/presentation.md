# Цели и задачи работы

## Цель лабораторной работы

Изучить возможности протокола **STP** и его модификации **Rapid PVST+** по обеспечению отказоустойчивости сети, а также освоить агрегирование каналов между коммутаторами.

## Задачи

- сформировать резервное соединение между коммутаторами;
- исследовать прохождение трафика ICMP при работе STP;
- определить корневой коммутатор для **VLAN 3**;
- переназначить root bridge;
- включить режим **PortFast** на серверных портах;
- сравнить отказоустойчивость **STP** и **Rapid PVST+**;
- настроить агрегированный канал **EtherChannel**.

# Новый маршрут прохождения трафика

## Проверка маршрутов после смены root bridge

После перерасчёта STP трафик стал проходить следующим образом:

- до сервера **mail**:
  **dk-donskaya-1 → sw-1 → sw-3 → mail**
- до сервера **web**:
  **dk-donskaya-1 → sw-1 → sw-2 → web**

Это подтвердило корректное изменение логического дерева STP.

# Настройка PortFast

## Включение PortFast на серверных портах

Назначение PortFast:

- ускоренный переход access-порта в состояние **Forwarding**;
- сокращение времени ожидания при подключении серверов;
- применение только на портах, ведущих к конечным устройствам.

- уменьшение времени простоя сети при отказе линка.

# EtherChannel

## Формирование агрегированного канала

Преимущества агрегирования:

- увеличение пропускной способности;
- логическое объединение нескольких физических каналов;
- повышение отказоустойчивости.

## Схема агрегированного соединения

![Агрегированное соединение между коммутаторами msk-donskaya-sw-1 и msk-donskaya-sw-4](13.png){ width=88% }

## Настройка EtherChannel

Использованные сущности Cisco:

- **EtherChannel** — технология агрегирования;
- **port-channel** — логический интерфейс;
- **channel-group** — привязка физических портов к логическому каналу.
