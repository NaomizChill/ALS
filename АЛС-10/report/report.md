# Контрольные вопросы

**1. Как задать действие правила для конкретного протокола?**  

Для этого в записи ACL после действия **permit** или **deny** указывается нужный протокол.  
Например:
- **permit tcp ...** — разрешить TCP-трафик;
- **deny udp ...** — запретить UDP-трафик;
- **permit icmp ...** — разрешить ICMP-запросы;
- **permit ip ...** — правило сразу для всех IP-протоколов.

**2. Как задать действие правила сразу для нескольких портов?**  

Для этого в расширенных ACL можно использовать:
- **eq** — для одного конкретного порта;
- **range** — для диапазона портов.

Если нужно задать правило сразу для нескольких портов, обычно используют диапазон:
- **permit tcp host 10.128.6.200 host 10.128.0.2 range 20 21**

Такое правило, например, разрешает доступ сразу к портам с 20 по 21.  
Если нужные порты не образуют непрерывный диапазон, тогда создают несколько отдельных правил — по одному на каждый порт или сервис.

**3. Как узнать номер правила в списке прав доступа?**  

Номер правила можно посмотреть командой:

**show access-lists**

При выводе списка рядом с каждой строкой отображается её порядковый номер.  
Например:
- **10 permit tcp any host 10.128.0.2 eq www**
- **20 permit tcp host 10.128.6.200 host 10.128.0.2 range 20 ftp**

Этот номер используется для анализа списка и для вставки новых правил в нужное место.

**4. Каким образом можно изменить порядок применения правил в списке контроля доступа?**  

Порядок важен, потому что ACL обрабатывается сверху вниз, и применяется первое подходящее правило.  
Изменить порядок можно двумя способами:

1. Добавить новое правило с указанием номера строки перед существующими правилами.  
   Например:
   **1 permit icmp any any**

2. Удалить нужное правило и создать его заново в другой позиции списка.

На практике чаще используется первый способ — явное указание номера строки, так как он позволяет вставить правило в начало или середину ACL без полной перенастройки списка.
