# Цель и содержание работы

## Цель работы

Провести подготовительные мероприятия по подключению локальной сети организации к Интернету.

## Основные задачи

- Построить схему подключения локальной сети **«Донская»** к сети провайдера и модельной сети Интернет.
- Выполнить проектирование на уровнях **L1, L2 и L3**.
- Добавить оборудование провайдера и модельной сети Интернет в Cisco Packet Tracer.
- Настроить IP-адресацию серверов модельной сети Интернет.
- Подготовить DNS-записи для доступа к внутренним и внешним ресурсам.
- Сформировать таблицы VLAN, портов и подсетей.

# Построение топологии сети

## Логическая схема L1

- В Cisco Packet Tracer построена схема подключения локальной сети к провайдеру и модельной сети Интернет.
- В топологию включены:
  - маршрутизаторы,
  - коммутаторы,
  - медиаконвертеры,
  - серверы,
  - оконечные устройства пользователей.
- Для сети провайдера и модельной сети Интернет добавлены:
  - **4 медиаконвертера Repeater-PT**;
  - **2 коммутатора Cisco 2960-24TT**;
  - **1 маршрутизатор Cisco 2811**;
  - **4 сервера**.

## Логическая схема L1

## Схема L2: VLAN-сегментация

- На канальном уровне выделены VLAN локальной сети, сети провайдера и модельного Интернета.
- Использованы следующие VLAN:
  - **VLAN 4** — сеть провайдера;
  - **VLAN 2** — сеть управления;
  - **VLAN 3** — серверная ферма;
  - **VLAN 101–104** — пользовательские сегменты.
- Между коммутаторами настроены магистральные соединения **trunk** для передачи нескольких VLAN.

## Схема L2: VLAN-сегментация

![Схема L2 с указанием VLAN](L2.png){ width=82% }

## Схема L3: IP-адресация

- На сетевом уровне выполнено распределение адресного пространства.
- Использованы подсети:
  - **192.0.2.0/24** — модельная сеть Интернет;
  - **198.51.100.0/24** — сеть провайдера;
  - **10.128.0.0/24** — серверная ферма;
  - **10.128.1.0/24** — управление;
  - **10.128.3.0/24** — дисплейные классы;
  - **10.128.4.0/24** — кафедры;
  - **10.128.5.0/24** — администрация;
  - **10.128.6.0/24** — другие пользователи.

# Выводы

В ходе лабораторной работы была построена схема подключения локальной сети к модельной сети Интернет через сеть провайдера.

В результате выполнения работы:

- разработаны схемы уровней **L1, L2 и L3**;
- реализована физическая, канальная и сетевая структура сети;
- выполнено разделение сети на VLAN;
- настроена IP-адресация внутренних и внешних сегментов;
- подготовлены DNS-записи для доступа к ресурсам по доменным именам;
- сформирована работоспособная модель взаимодействия локальной инфраструктуры с внешними ресурсами.
