# Цели и задачи работы

## Цель лабораторной работы

Приобрести практические навыки настройки доступа локальной сети организации к внешней сети с использованием технологии **NAT**.

## Задачи

- Выполнить первоначальную настройку оборудования провайдера.
- Настроить интерфейсы маршрутизатора и коммутатора провайдера.
- Подключить маршрутизатор сети «Донская» к сети провайдера.
- Настроить NAT для выхода локальной сети во внешнюю сеть.
- Настроить доступ из внешней сети к внутренним серверам.
- Проверить корректность правил доступа и трансляции адресов.

# Настройка NAT

## Основные параметры NAT

Для выхода локальной сети во внешнюю сеть был настроен NAT overload:

- создан ACL **nat-inet**
- создан пул внешних адресов **main-pool**
- диапазон пула: **198.51.100.2–198.51.100.14**
- маска: **255.255.255.240**
- внутренние интерфейсы отмечены как **ip nat inside**
- внешний интерфейс отмечен как **ip nat outside**
