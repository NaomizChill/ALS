# Цель работы

Приобретение практических навыков по настройке доступа локальной сети к внешней сети посредством NAT.

# Ход выполнения

Была выполнена настройка сетевого оборудования для подключения локальной сети организации «Донская» к сети провайдера. В ходе работы настроены маршрутизатор **provider-gw-1**, коммутатор **provider-sw-1**, внешний интерфейс маршрутизатора **msk-donskaya-irkolontirskiy-gw-1**, а также правила **NAT** для доступа локальной сети во внешнюю сеть и обратного доступа к внутренним сервисам.

На маршрутизаторе была создана расширенная ACL **nat-inet**, определяющая трафик, разрешённый для трансляции. Для выхода пользователей во внешнюю сеть был настроен пул адресов **main-pool** в диапазоне **198.51.100.2–198.51.100.14** с маской **255.255.255.240**, после чего включён NAT overload.

Внутренние подинтерфейсы были обозначены как **ip nat inside**, а внешний подинтерфейс **FastEthernet0/1.4** — как **ip nat outside**.

![Настройка NAT overload и обозначение NAT-интерфейсов](Screenshot_4.png){ #fig:004 width=85% }

# Контрольные вопросы

**1. В чём состоит основной принцип работы NAT (что даёт наличие NAT в сети организации)?**  

NAT (Network Address Translation) — это механизм преобразования IP-адресов, при котором внутренние (частные) адреса сети заменяются на внешние (публичные) при выходе в Интернет.  

Основной принцип заключается в том, что маршрутизатор изменяет IP-адрес отправителя (и при необходимости порт), запоминая соответствие между внутренним и внешним адресом.  

Наличие NAT в сети даёт:
- возможность использовать частные IP-адреса внутри организации;
- экономию публичных IP-адресов;
- скрытие внутренней структуры сети;
- повышение безопасности за счёт отсутствия прямого доступа извне.

**2. В чём состоит принцип настройки NAT (на каком оборудовании и что нужно настроить для выхода из локальной сети во внешнюю сеть через NAT)?**  

NAT настраивается на маршрутизаторе, который соединяет локальную сеть с внешней сетью (Интернетом).  

Для настройки необходимо:
- определить внутренние и внешние интерфейсы (`ip nat inside` и `ip nat outside`);
- создать список доступа (ACL), определяющий трафик для трансляции;
- задать пул внешних IP-адресов или использовать один адрес;
- настроить правило NAT (например, overload/PAT);
- при необходимости настроить статические преобразования для серверов.

Таким образом, весь исходящий трафик из локальной сети будет преобразовываться и передаваться во внешнюю сеть через маршрутизатор.

**3. Можно ли применить Cisco IOS NAT к субинтерфейсам?**  

Да, NAT в Cisco IOS можно применять к субинтерфейсам.  

Субинтерфейсы часто используются при работе с VLAN (например, схема router-on-a-stick), и для них также можно указывать роли:
- `ip nat inside` для внутренних VLAN;
- `ip nat outside` для внешнего подключения.

Это позволяет выполнять трансляцию адресов даже при использовании логического разделения интерфейсов.

**4. Что такое пулы IP NAT?**  

Пул NAT — это диапазон публичных IP-адресов, который используется для трансляции внутренних адресов во внешние.  

При использовании пула каждому внутреннему устройству может быть временно назначен один из внешних адресов из этого диапазона.  

Пулы применяются:
- при динамическом NAT;
- при PAT (overload), когда используется один или несколько адресов с различием по портам.

**5. Что такое статические преобразования NAT?**  

Статический NAT — это фиксированное соответствие между внутренним и внешним IP-адресом (или адресом и портом).  

Такое преобразование задаётся вручную и не изменяется со временем.  

Используется для:
- публикации внутренних серверов во внешнюю сеть;
- обеспечения постоянного доступа к сервисам (WEB, FTP, почта и т.д.);
- сопоставления конкретных портов внешнего адреса внутренним ресурсам.

В отличие от динамического NAT, статический NAT обеспечивает постоянное и предсказуемое соответствие адресов.
