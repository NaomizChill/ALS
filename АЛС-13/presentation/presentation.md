# Цели и задачи работы

## Цель лабораторной работы

Провести подготовительные мероприятия по организации взаимодействия через сеть провайдера посредством статической маршрутизации локальной сети с:

- сетью основного здания, расположенного в **42-м квартале в Москве**;
- сетью филиала, расположенного **в г. Сочи**.

## Задачи

- Добавить в проект подсеть 42-го квартала в Москве.
- Добавить в проект подсеть филиала в г. Сочи.
- Обновить схемы **L1**, **L2** и **L3**.
- Разместить новые объекты на физической карте проекта.
- Выполнить первоначальную настройку добавленного оборудования.
- Подготовить проект к дальнейшей настройке статической маршрутизации.

# Первоначальная настройка оборудования

## Выполненные действия

На добавленных устройствах была выполнена единая базовая настройка:

- назначение имени устройства;
- настройка пароля для консольного доступа;
- настройка пароля для удалённого доступа через VTY;
- включение авторизации;
- настройка **enable secret**;
- включение шифрования паролей;
- создание пользователя **admin**;
- настройка доменного имени;
- генерация RSA-ключей;
- включение доступа по SSH;
- сохранение конфигурации.

# Выводы

## Вывод

В ходе лабораторной работы структура сетевого проекта была расширена.

В общую корпоративную сеть были добавлены:

- подсеть основной территории организации **42-го квартала в Москве**;
- подсеть **общежития**;
- подсеть филиала **в г. Сочи**.

Для новых сегментов были обновлены схемы **L1**, **L2** и **L3**, а также выполнена первоначальная настройка добавленного оборудования.
